# Security review checkpoint

Date: 2026-10-25
Baseline: `c484c42`
Scope: local static review of auth/session, invitation, Git HTTP/storage, PR/merge, admin and maintenance code. This is not a penetration test or cloud review.

## Findings and remediation

| Finding | Severity estimate | Remediation | Verification state |
| --- | --- | --- | --- |
| Direct Git receive-pack could update the default branch, allowing a WRITE member to bypass owner PR merge. | High; estimated CVSS 6.5 | Pre-receive rejects every update to an existing default branch. Only the owner may initialize an empty default branch; server-side PR merge uses compare-and-swap and bypasses receive-pack. | Hook regression tests pass for owner/WRITE update rejection, owner-only initial branch creation, and feature-branch push. Hosted PostgreSQL owner-merge E2E passes on run `40129005632`. |
| Server-side PR merge could create a target ref that exceeded file/repository logical quotas. | Medium; estimated CVSS 4.3 | Merge candidate objects are measured with `rev-list --objects --all` and `cat-file --batch-check` while the repository advisory lock is held; quota errors mark the durable operation failed before target ref CAS. | Real-Git unit tests pass for oversized-file and repository-total rejection; service unit test verifies no ref update and durable failure. Full quota API exercise remains unverified. |
| PR edits could race with collaborator permission removal or role downgrade. | Medium; estimated CVSS 4.3 | PR edit/close/reopen now uses the repository advisory lock and rechecks active user, repository state, membership, author and PR version in a database transaction before write/audit. | Unit test verifies a removed WRITE membership is denied before mutation. Concurrent PostgreSQL race test remains unverified. |
| Repository create/update/soft-delete/restore mutations were missing audit records. | Control gap | Added transaction-scoped allowlisted audit events. Details record IDs, changed field names, visibility transition and retention timestamp; no description, source, diff, token or credential is recorded. | Hosted PostgreSQL E2E passed on run `40129005632`; local database listener remains unavailable. |
| Admin bootstrap CLI creates or promotes an admin without recording an audit event. | Low; auditability/control gap, not a demonstrated privilege bypass | Fixed: additive migration allows a null actor for explicit `SYSTEM_ADMIN_CREATED` / `SYSTEM_ADMIN_PROMOTED` events, written in the same transaction as the user mutation. Admin UI labels these as system bootstrap events; safe details expose only the channel. | Hosted run `40129005632` passed migration deploy, bootstrap create/promote PostgreSQL E2E assertions, and frontend suite. No secret-in-argv/output issue was found. |
| Requests behind a shared reverse proxy could share one IP throttling bucket. | Medium, deployment-dependent; estimated CVSS 5.3 for temporary availability impact | All 17 Next API routes and both server-rendered backend fetches now sign Vercel's platform-overwritten `x-forwarded-for` IP with a server-only HMAC secret; backend accepts only a valid signature and otherwise uses Express peer IP. Express proxy trust is configurable by explicit hop count and defaults to zero. | Backend signature/config tests pass locally; latest hosted workflow `40145289400` passes all gates. Vercel documents that it overwrites `X-Forwarded-For` with the client IP. Actual Vercel→Render traffic, Render hop count, direct-backend behavior, and direct Git attribution remain unverified. |
| Successful ordinary Git pushes lack a durable attributable audit of actual ref changes. | P2 operational/security-control gap; no exploit/CVSS assigned | Open: persist a push journal under the repository lock, compute actual ref delta after Git child completion, atomically audit success, and reconcile crash-left operations. Fail closed on ambiguity and keep source/pack/credentials out of logs and audit API. | Confirmed by read-only review at `a5739cd`; tracked by [issue #5](https://github.com/VuLeCoder/Code-forge/issues/5). Related merge and admin audit tests pass in hosted workflow `40145289400`; push audit implementation is not yet done. |
| Missing baseline anti-frame/security response headers. | Low–medium, deployment-dependent | Added CSP `frame-ancestors 'none'`, `X-Frame-Options`, `X-Content-Type-Options`, `Referrer-Policy` and restrictive `Permissions-Policy` in Next config. | Previously verified from `GET /login`. HSTS remains the TLS edge's responsibility. |
